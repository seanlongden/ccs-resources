# Completed Routine Register
Pack: 0.2.0-preview. All routines are proposed, NONE ACTIVE.
Daily Reply Review: weekday 09:00 Europe/London; read new reply events; deduplicate by stable event/thread ID; return decision cards; owner checks them. Missing access returns FAILED, not zero replies.
Daily Scoreboard: weekday 17:00; read selected campaign; count new contacts, sends, interested replies and bookings separately; owner checks anomalies.
Weekly Review: Friday 16:00; compare equivalent reporting windows, health, remaining new contacts and cost; propose one next action.
Refill: owner-triggered when fewer than five sending days of NEW contacts remain. Draft search and cost request first.
Failure: hold affected job, record last good run, error, ambiguous state and owner action. No automatic send/retry. These schedules have not been created or tested in Grok.
